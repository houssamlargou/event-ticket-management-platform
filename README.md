# 🎟️ Event & Ticket Management Platform (ETM)

A full-stack web application to manage events, tickets, orders, and user interactions.

---

## 🚀 Features

### 👤 User
- Browse events
- Filter events (city, time)
- View event details
- Add/remove favorites
- Buy tickets
- View orders
- Comment on events

### 🧑‍💼 Organizer
- Create events
- Edit/delete own events
- Add tickets to events
- View own events
- Receive notifications for comments

### 🛡️ Admin
- Dashboard
- Approve/reject events
- Delete events
- View users
- Review events in detail

---

## ⚙️ Tech Stack

### Backend
- Laravel
- Laravel Sanctum (Auth)
- PostgreSQL
- Docker

### Frontend
- Vue 3
- Vue Router
- Axios
- Tailwind CSS
